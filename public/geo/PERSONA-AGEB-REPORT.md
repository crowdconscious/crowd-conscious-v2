## Method

1. **Alcaldía filter.** Only Cuauhtémoc and Miguel Hidalgo are in scope (AGEB GeoJSON). Others stay unassigned.
2. **Colonia → AGEB candidates.** Intersect official colonia polygon(s) with each AGEB in the alcaldía (metric EPSG:32614). Drop **slivers** where intersection &lt; 10% of AGEB area **and** &lt; 10% of colonia area. **"Popo" matches only "Popo"**, never Popotla / Ampliación Popo.
3. **Fallback.** If the colonia string matches no official name, or no candidates survive the sliver filter, candidates = all AGEBs in the persona's alcaldía (`alcaldia_fallback`).
4. **Weights.** `P_18YMAS × (intersection_area / AGEB_area)` — expected adults of that AGEB living inside the colonia. Fallback to `POBTOT` fraction if P_18YMAS missing/zero. No NSE secondary proxy.
5. **Determinism.** Pick seeded by `hash(persona.id)` (`ageb-pick:<id>`). Re-runs with the same ids yield identical AGEBs.
6. **Placement.** Point-on-surface of the **colonia∩AGEB intersection** polygon, plus deterministic jitter (`ageb-jitter:<id>`) kept inside that intersection (not the raw AGEB centroid).
